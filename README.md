# Robust Multimodal Deepfake Analysis

Detects deepfake videos using both the **face** (video) and the **voice** (audio). It is meant to stay reliable under compression and noise, and it explains its decisions with Grad-CAM heatmaps.

```
video ──► 16 face crops ──► EfficientNet-B0 ──┐
     └──► log-mel spectrogram ──► ResNet-18 ──┴─► fusion ──► P(fake) + per-modality scores + heatmaps
```

See [PLAN.md](PLAN.md) for the roadmap, [TASKS.md](TASKS.md) for the detailed task tracker, and [DATASETS.md](DATASETS.md) for how to get the data.

## Quick start

### On your Mac (writing code, running tests)
```bash
uv venv --python 3.11 .venv          # or: python3.11 -m venv .venv
source .venv/bin/activate
uv pip install -r requirements.txt   # or: pip install -r requirements.txt
pip install -e .
pytest                               # 49 tests, uses synthetic videos (needs ffmpeg)
```

### On Google Colab (downloading data, training)
1. The notebooks clone this repo automatically (`REPO_URL` in the setup cell).
2. Open the notebooks in order:
   - `notebooks/00_colab_setup.ipynb`: GPU check, install, tests.
   - `notebooks/01_download_datasets.ipynb`: downloads, manifests, splits.
   - `notebooks/02_preprocess.ipynb`: face crops and spectrograms saved to Drive.
   - `notebooks/03_train_visual.ipynb`: Phase 2, train and evaluate the visual branch.
   - `notebooks/04_train_audio.ipynb`: Phase 3, audio branch (ASVspoof pre-training, then FakeAVCeleb fine-tuning).
   - `notebooks/05_train_fusion.ipynb`: Phase 4, late and intermediate fusion, plus the comparison table.
   - `notebooks/06_robustness.ipynb`: Phase 5, stress tests and robust fine-tuning.
   - `notebooks/07_explainability.ipynb`: Phase 6, Grad-CAM gallery and single-clip explanations.

Notebooks are generated by `scripts/make_notebooks.py`. Edit that script, then re-run it.

## Command-line tools
```bash
python -m deepfake.data.download status            # what's downloaded
python -m deepfake.data.download asvspoof          # dfdc | asvspoof | fakeavceleb | celebdf
python -m deepfake.data.manifest all               # unified CSV per dataset
python -m deepfake.data.splits dfdc                # identity-wise train/val/test
python -m deepfake.preprocessing.run dfdc          # faces + spectrograms
python -m deepfake.preprocessing.run --input my_videos/ --out out/   # any folder of videos
python -m deepfake.training.train_visual --dataset dfdc           # train visual branch (resumable)
python -m deepfake.training.train_audio --dataset asvspoof        # train audio branch
python -m deepfake.training.train_audio --dataset fakeavceleb --init-from <run>/best.pt   # fine-tune
python -m deepfake.training.train_fusion --fusion late --visual-ckpt V.pt --audio-ckpt A.pt  # or intermediate
python -m deepfake.evaluation.compare --dataset fakeavceleb --model visual_only=V.pt --model late=L.pt ...
python -m deepfake.evaluation.robustness_eval --label overall --limit 300 --model fused=F.pt ...  # stress test
python -m deepfake.training.train_visual --dataset fakeavceleb --robust-augment --init-from V.pt  # robust training
python -m deepfake.explainability.gallery --checkpoint F.pt --dataset fakeavceleb                # Grad-CAM gallery
python -m deepfake.evaluation.evaluate --checkpoint <run>/best.pt --dataset celebdf   # cross-dataset
```

## Project layout
```
configs/default.yaml      all settings (frames, image size, audio params, training)
src/deepfake/
  config.py               config + Mac/Colab path resolution
  data/                   download.py · manifest.py · splits.py
  preprocessing/          frames.py · faces.py (YuNet) · audio.py · run.py (faces + mel + wav)
  datasets/               PyTorch datasets (visual / audio / multimodal)
  models/                 visual.py · audio.py · fusion.py
  evaluation/             metrics.py · evaluate.py (+ per-category) · compare.py · robustness_eval.py · plots.py
  robustness/             degradations.py (JPEG, H.264, blur, noise, downscale, MP3, audio noise)
  explainability/         gradcam.py (faces + spectrogram) · gallery.py
  training/               engine.py · tasks.py · runner.py · train_visual.py · train_audio.py · train_fusion.py
app/app.py                Gradio demo (Phase 7)
notebooks/                Colab runners
scripts/make_notebooks.py generates notebooks/
reports/results.md        results template, filled in as training runs finish
tests/                    pytest suite
```
